# AI Reasoning Output

The AI explanation is intentionally presentation-friendly. It uses six short sections:

1. What changed?
2. What happened after correction?
3. Why were these decisions affected?
4. Why were the other decisions not affected?
5. Why is selective rewind safe?
6. Evidence

The deterministic Decision Rewind engine remains authoritative. The LLM explains the historical, counterfactual, provenance, and universal-log evidence; it does not decide which records to rewind.

The frontend renders the headings, bullets, and emphasis as readable UI instead of displaying raw Markdown syntax.
