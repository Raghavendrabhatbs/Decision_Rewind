# LLM Role

The LLM is an evidence-grounded explanation and reasoning layer; it is not the authority that decides recovery actions.

For a selected dataset/event, the backend supplies:

- the historical and current event state
- the proposed correction
- the existing model ID/version
- counterfactual outputs generated by re-running the existing trained model on corrected historical input
- historical/current/counterfactual decision comparisons
- affected and unaffected decisions from deterministic impact analysis
- explicit feature → decision provenance paths
- universal-log evidence scoped to the question, dataset, event, features, and decisions
- verification/audit information when available

The LLM must explain the deterministic result, never invent a dependency or log event, and explicitly state when evidence is missing. The model is not retrained during counterfactual replay.
